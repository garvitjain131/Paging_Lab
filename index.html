How does this connect to the research paper?

Peter J. Denning's working set is the set of pages referenced during a recent interval of process execution. Our teaching version uses the last k page requests. If this set is larger than RAM capacity, it signals memory pressure and a risk of thrashing. It does not prove that thrashing is occurring.

The tracker is not a third replacement algorithm. Denning also connects memory allocation to process scheduling, which this single-process simulator does not implement.
